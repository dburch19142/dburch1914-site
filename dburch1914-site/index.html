Playwright Test Framework

2026 · TypeScript · Source code

A reusable starting point for UI and API test automation, built the way I would set one up for a new team.

  • Page objects hold locators and actions only; assertions stay in the specs, so a UI change is fixed in one place.
  • Custom fixtures inject page objects and seed test data through the API, and a setup project signs in once and reuses the saved session.
  • UI and API specs run in the same suite, with smoke tests tagged so they can run alone.
  • A GitHub Actions workflow runs the suite on every push and pull request and keeps the HTML report; failures keep a trace, screenshot and video.

NFL Fantasy Lab

A Flask app that builds FanDuel lineups with a linear-programming optimizer and predicts game outcomes, covered by a pytest suite at every layer.
